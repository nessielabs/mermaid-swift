# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a
public issue for security reports.

Include the Mermaid source (or a minimal reproduction) and the affected
version. MermaidSwift parses untrusted diagram source, so reports of
crashes, hangs, or excessive memory or CPU use on crafted input are in
scope.

## Supported versions

Security fixes are released for the latest minor version.
